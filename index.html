🔵 Procesos lógicos

Son estructuras del simulador (JavaScript). Representan unidades de trabajo con llegada, ráfaga y estado. No son hilos reales.

🧵 Hilos reales (C++)

Se crean con std::thread. Su ejecución la decide el SO real, no el planificador académico del simulador.

⚙️ Planificador académico

Implementado en JS/C++. Decide el orden según FIFO, SJF o RR usando un reloj lógico, no el tiempo real.

Herramientas de C++ usadas

  • std::thread — crea hilos.
  • std::mutex — protege datos compartidos.
  • std::lock_guard — bloqueo RAII seguro.
  • std::condition_variable — espera/notificación entre hilos.
  • std::join() — espera a que un hilo termine.

⚠️ Crear un hilo por proceso no hace que el SO respete FIFO/SJF/RR automáticamente. La coordinación debe ser explícita (mutex + condition_variable). El código C++ de referencia se muestra en la sección “Código C++”.

Explicación del bloque

Ayuda y conceptos teóricos

FIFO / FCFS

Ejecuta primero el proceso que llegó antes. No apropiativo. Puede provocar efecto convoy (procesos cortos esperan detrás de uno largo).

SJF no apropiativo

Elige el proceso disponible con menor ráfaga. Minimiza la espera promedio, pero puede producir inanición de procesos largos. Empates: llegada, luego ID.

Round Robin

Cada proceso recibe un quantum. Si no termina, vuelve al final de la cola. Si llega un proceso en el mismo instante en que termina un quantum, se encola antes de reinsertar el proceso interrumpido (criterio definido explícitamente).

Métricas

TR = Fin − Llegada · TE = TR − Ráfaga · TRes = Primer inicio − Llegada. Se calculan con reloj lógico, no con tiempo real de ejecución.
